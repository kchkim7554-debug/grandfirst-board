# 게시물 기한관리 — 제일풍경채 그랑퍼스트 1단지

아파트 내부 게시판(공동현관 홀 · 엘리베이터)에 붙인 게시물의 **기한(탈착일)을 관리하는 조회 전용 웹 대시보드**입니다.
경비원 8명이 휴대폰으로 링크만 열어 현황을 확인합니다. 수정은 관리자(카일 님)가 `data.json`으로 합니다.

- 공개 주소: **https://kchkim7554-debug.github.io/grandfirst-board/**
- 별도 서버·로그인·설치 없이 동작하는 정적 페이지입니다.

## 화면

| 탭 | 내용 |
|---|---|
| **동별 현황** | 오늘 탈착 대상 배너 · 요약 숫자 · 구역(정문/후문A/후문B) 필터 · 101~124동 격자 |
| **동 상세** | 라인(코어) → 층(1층/지하1층/지하2층) 또는 엘리베이터(호기) 선택 → 실제 게시판 그림(공동현관 01~12번, 엘리베이터 01~06번) → 번호를 누르면 게시물·기한·사진 |
| **탈착 목록** | 기한 경과 / 오늘 / 내일 / 7일 이내 / 게시 중. 원터치 복사(카카오톡 붙여넣기용) |
| **보관함** | 탈착 완료된 게시물을 탈착일자별로 보관 |

- 색: 빈 게시판(회색 점선) · 게시 중(초록) · 7일 이내(파랑) · 내일(노랑) · 오늘(주황) · 기한 경과(빨강) · 상시(보라)
- 한 번호에 여러 장이 겹치면 **1번째·2번째** 순번과 겹침 개수 배지가 표시됩니다.
- 오른쪽 위 `가+` 버튼으로 글자 크기를 키울 수 있습니다(경비원용).

## 단지 구조 (데이터 기준)

- 24개동(101~124동) · 40개 코어 · 공동현관 홀 **120개 게시판**(40 × 3개 층) · 엘리베이터 **44대**
- 정문: 101~108동 (14코어, 게시판 42, 승강기 16)
- 후문A: 109·110·116~122동 (14코어, 게시판 42, 승강기 14)
- 후문B: 111~115·123·124동 (12코어, 게시판 36, 승강기 14)
- 4라인 동(101·103·105~112·114·116~118·123·124): 코어 2개(1·2라인, 3·5라인), 각 1대
- 3라인 동(102·104·113·115): 코어 1개(1·2·3라인), 승강기 2대(1호기 우측 / 2호기 좌측)
- 2라인 동(119~122): 코어 1개(1·2라인), 1대

## 파일

```
index.html   화면 전체(HTML/CSS/JS) + data.json 인라인 사본
data.json    게시물 데이터(원본)
images/      게시물 사진
build.py     data.json → index.html 인라인 사본 갱신
.nojekyll    GitHub Pages Jekyll 처리 생략
```

`index.html`은 `data.json`을 먼저 불러오고, 실패하면(예: 파일을 직접 열 때) 안에 심어둔 사본을 씁니다.
그래서 **웹에서는 data.json만 고쳐 올리면 되고**, 파일로 열 때도 최신 내용이 보입니다.
인라인 사본까지 맞추려면 `python3 build.py`를 실행하세요.

## 게시물 추가·수정

`data.json`의 `notices` 배열에 한 건을 넣습니다.

```json
{
  "id": "N07",
  "title": "겨울철 제설 작업 안내",
  "category": "안내문",
  "postedAt": "2026-11-20",
  "deadline": "2026-12-05",       // 상시 게시물이면 null + "permanent": true
  "permanent": false,
  "isTest": false,
  "photo": "images/n07.jpg",       // 없으면 null
  "targets": [
    { "buildings": "all", "board": "lobby",    "floors": ["1층","지하1층","지하2층"], "slot": "04", "order": 1 },
    { "buildings": [101, 102], "board": "elevator", "elevators": "all", "slot": "03", "order": 1 }
  ],
  "removedAt": null                // 탈착 완료 시 "2026-12-05" 처럼 날짜 입력 → 보관함으로 이동
}
```

- `buildings`: `"all"` 또는 동 번호 배열
- `board`: `"lobby"`(공동현관, `floors` 사용) / `"elevator"`(`elevators` 사용: `"all"` 또는 `["1","2"]`)
- `slot`: 공동현관 `01`~`12`, 엘리베이터 `01`~`06` (04=우측 액자 위, 05=정면 거울 아래, 06=좌측)
- `order`: 같은 번호에 겹쳐 붙일 때 순번(1번째=1)
- 상태(오늘/내일/기한 경과)는 오늘 날짜와 `deadline`을 비교해 자동 계산됩니다.

수정 후:

```bash
python3 build.py
git add -A && git commit -m "게시물 갱신" && git push
```

## 테스트 데이터

지금 올라가 있는 6건(승강기 정기 점검 · 전기차 충전기 요금 변경 · 계약서 공개 · 주차장 운영규정 제정(안) · 세대 내 소방시설 자체 점검 · 슬기로운 공동주택 생활)은
PDF(2026-11-15) 16~19쪽 사진에서 뽑은 **테스트 데이터**이고, 보관함 확인용 예시 3건이 더 있습니다.
모두 `"isTest": true`라 화면에 `테스트` 표시가 붙습니다. 실제 데이터를 넣을 때 `notices`를 교체하면 됩니다.
